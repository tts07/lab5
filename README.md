# Лабораторная работа 5 — Обработка числовых рядов

Модульное консольное приложение для генерации числовых рядов,
расчёта статистики и скользящих средних.

## Запуск
python main.py --kind sine -n 20 --window 3 --alpha 0.3 --seed 7

## Параметры
- `--kind` — тип ряда: random, sine, trend
- `-n` — количество точек
- `--window` — окно для скользящей средней
- `--alpha` — коэффициент для EMA
- `--seed` — зерно ГПСЧ
- `--load PATH` — загрузить ряд из файла
- `--save PATH` — сохранить ряд в JSON
